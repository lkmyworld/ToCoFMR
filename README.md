# ToCoFMR

This repository hosts the official PyTorch implementation of our paper:

> **ToCoFMR: Topology-preserving Collaborative Flow Matching for Incomplete Multimodal Recommendation**

## Dataset

The Baby dataset and multimodal features are located in `data/baby/`.

## Configuration

- General settings: `src/configs/overall.yaml`
- Dataset settings: `src/configs/dataset/baby.yaml`
- Model hyperparameters: `src/configs/model/ToCoFMR.yaml`
